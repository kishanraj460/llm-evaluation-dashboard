# 📊 LLM Evaluation Dashboard: English vs Hindi

An executive-level, dark-mode Power BI dashboard designed to evaluate and compare Large Language Model (LLM) performance across English and Hindi prompt benchmarks.

## 🚀 Key Features
* **Custom Dark-Mode Design System:** Dark charcoal theme (`#1E1E1E`), 8px rounded borders (`#333333`), and colored accent bars on KPI cards.
* **Interactive Matrix Heatmap:** Performance metrics across 4 categories (*Factual QA*, *Instruction Following*, *Nuance & Localization*, *Reasoning & Logic*) using a custom green color scale.
* **Comparative Language Analysis:** Clustered column charts tracking Correctness, Relevance, and Fluency side-by-side for English and Hindi models.
* **Analytical Transparency:** Executive "Key Findings" panel documenting prompt set variations and data caveats.

## 🛠️ Tech Stack
* **Analytics & Visualization:** Power BI Desktop
* **Data Source:** Structured evaluation dataset (100 prompts)
* **Key Metrics:** Correctness, Relevance, Fluency

## 📂 Repository Structure
* `Model_Eval_Dashboard.pbix` — Interactive Power BI dashboard file.
* `FINAL_MASTER_EVAL_DATA.xlsx` — Underlying evaluation dataset across 100 benchmark prompts.
* `dashboard.pdf` — Static PDF export of the completed dashboard.
